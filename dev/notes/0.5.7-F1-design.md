# 0.5.7 F-1 — admission response signaling

Successful admission remains request metadata until the post-call header hook,
which emits `X-Airlock-Admission: admitted` only when the gate stamped that
state. The disabled-gate path does not stamp metadata and therefore emits no
admission header.

Shedding is a typed `AirlockAdmissionShed` exception rather than a plain
`ValueError`. Its FastAPI handler owns the OpenAI-shaped 429 body and emits both
`Retry-After` and `X-Airlock-Admission: shed; retry_after=N`, using the existing
whole-second ceiling helper. This keeps actual backpressure distinguishable from
upstream provider 429 responses.
