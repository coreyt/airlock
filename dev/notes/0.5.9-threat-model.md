# 0.5.9 design/threat-model review

Reviewed before implementation of LLM analysis and code-inspection signals.

* Code inspection is observational by default.  It reports pattern categories
  and counts; its default enforcement weight is zero.
* TUI mutation views use the canonical ledger only and render redacted values
  as a redaction marker, not the original content.
* Analyzer model output is validated structured advisory content.  Tool calls
  are allowlisted analysis queries and cannot mutate Airlock.
* Managed MCP readiness applies only to `airlock_managed` entries with a health
  URL.  Expiry terminates the owned child and leaves it stopped.

Residual risk: pattern matching can have false positives; no default blocking
is added.  Remote analysis must be explicitly configured and is sent only
reduced, redacted evidence.
