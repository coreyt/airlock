## Threat model and privacy boundary

The analyzer is strictly advisory.  Its normal mode is a client-side,
read-only tool loop over derived aggregates and redacted/capped evidence.  It
does not receive credentials from logs, raw response/message bodies, files,
shell access, network tools, configuration mutation, or knob-write tools.
Remote sandbox execution is separately opted in and receives the same reduced
dataset only.  Guardrail inspection records categories/counts and safe
representations, never values that were redacted by another guardrail.

Adaptive classifier selection remains opt-in.  Legacy classifiers always run;
only explicitly annotated classifiers can be skipped.  A missed expected block
in the corpus equivalence report is release evidence to retain opt-in status,
not an authorization to alter enforcement.
