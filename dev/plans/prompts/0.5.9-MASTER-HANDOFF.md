## Approved implementation direction

Implement the [two-tier input prompt-injection design](../../notes/design-prompt-injection-classifier.md):

1. `input_injection_tripwire`: a light, deterministic classifier for clear
   known attack forms, sharing safe categories rather than matched text.
2. `model_armor_prompt_injection`: a heavy, direct Google Model Armor adapter
   for semantic prompt-injection detection, enabled only with explicit template
   configuration and Google application-default/workload credentials.

The adapter calls Model Armor directly, never back through Airlock. It receives
post-redaction, user-originated text and explicit MCP arguments only in Phase A.
Indirect retrieved/document and MCP-result protection is a distinct Phase B;
do not overclaim it as complete. Semantic enforcement needs explicit
`observe` → `shadow` → `enforce` behavior so a positive observed verdict is
not accidentally raised as a blocked request.

## Required next sequence

1. Implement the bootstrap, role-preserving direct-input extraction, light
